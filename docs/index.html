Prototype firstทำ prototype ก่อน

A clickable HTML prototype you change in seconds, round after round, then hand to SwiftUI as the spec: its own functions give your tests their expected values, and its strings become Localizable.strings — with a check that stops on a key two string tables define differently.prototype HTML ที่กดได้จริง แก้ได้ในไม่กี่วินาทีทุกรอบ แล้วส่งต่อเป็นสเปกให้ SwiftUI: ฟังก์ชันใน prototype ให้ค่าที่ test ต้องได้ และข้อความกลายเป็น Localizable.strings พร้อมตัวเช็คที่หยุดเมื่อคีย์เดียวกันมีข้อความไม่ตรงกันในสองตาราง

index.html  →  Localizable.strings + expected test values

App scaffoldโครงแอป

A Dock app from a Swift Package, a build script that makes a signed .app, and the fix most people miss: swift build stamps the binary with SDK 14, so macOS 26 draws it without Liquid Glass.แอปบน Dock จาก Swift Package สคริปต์ build ที่ได้ .app ที่ sign แล้ว และจุดที่หลายคนพลาด: swift build ประทับ SDK เป็น 14 macOS 26 เลยไม่แสดง Liquid Glass

sdk 14.0  →  sdk 27.0

Liquid GlassLiquid Glass

Glass surfaces and buttons on macOS 26, a matching material on macOS 14 and 15 — from three modifiers, so no availability checks spread through your views.พื้นผิวและปุ่มกระจกบน macOS 26 และ material ที่ใกล้เคียงบน macOS 14–15 จาก modifier 3 ตัว ไม่ต้องเช็กเวอร์ชันกระจายทั่วโค้ด

Tool-window panelsแผงเครื่องมือ

An IDE-style icon rail: one panel at a time, ⌥⌘ shortcuts, and panels that keep their state when you switch — a chat stays where it was.แถบไอคอนแบบ IDE เปิดทีละแผง มีคีย์ลัด ⌥⌘ และสลับแผงแล้วข้อมูลไม่หาย แชตก็ยังอยู่ที่เดิม

Accent and gradient themesสีและธีม

Light, Dark or System; 16 accents measured to read well in both modes; 8 gradient themes used as ambient light, never under text.โหมดสว่าง มืด หรือตามระบบ สี accent 16 สีที่วัดแล้วว่าอ่านง่ายทั้งสองโหมด และธีม gradient 8 แบบใช้เป็นแสงพื้นหลัง ไม่วางใต้ตัวหนังสือ
